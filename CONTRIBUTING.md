# Contributing

Thanks for your interest in Cupid.

- **Issues are welcome**: bug reports, feature requests and questions about the benchmark. Use the issue templates.
- **Pull requests are not accepted for now.** The code that ships is built from a private repository, so a merged PR here would not reach the product. If you have a fix, describe it in an issue; we'll credit you in the changelog if we use it.
- **Security problems** go to security@cupidcode.ai, not to issues. See [SECURITY.md](SECURITY.md).
- Please don't paste tokens, private code or other people's data into issues.

This project follows the [Contributor Covenant](CODE_OF_CONDUCT.md).
