# Cupid for VS Code

The VS Code extension is in progress and not yet on the Marketplace. Status and how it will work: [docs/install/vscode.md](../docs/install/vscode.md). Until then, run `cupid` in the VS Code integrated terminal.

The extension does not have its own engine: it starts your installed `cupid` binary with `cupid serve` and shares its account, sessions and settings.
