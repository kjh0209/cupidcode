# Install

Cupid works with four clients. One command installs the CLI and connects the others you have:

```
curl -fsSL https://cupidcode.ai/install.sh | sh
```

| Client | Guide |
|---|---|
| Cupid CLI (macOS, Linux, Windows) | [cupid-cli.md](cupid-cli.md) |
| Claude Code | [claude-code-codex-opencode.md](claude-code-codex-opencode.md) |
| Codex | [claude-code-codex-opencode.md](claude-code-codex-opencode.md) |
| OpenCode | [claude-code-codex-opencode.md](claude-code-codex-opencode.md) |
| VS Code (not yet released) | [vscode.md](vscode.md) |

`cupid connect` (Claude Code, Codex, OpenCode) runs on macOS and Linux; on Windows only the CLI installs for now.
